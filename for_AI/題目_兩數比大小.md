# 兩數比大小 (Compare Two Numbers)

## 問題描述

請寫一個程式，輸入兩個整數 A 和 B，比較它們的大小：
- 若 A 大於 B，輸出 `A > B`
- 若 A 小於 B，輸出 `A < B`
- 若兩者相等，輸出 `A == B`

## 題目說明

比較兩數大小是程式中控制流程的基礎技能。  
在 Python 中，關係運算子包括：
- `>`：大於
- `<`：小於
- `==`：等於（注意：兩個等號代表比較是否相等，一個等號代表變數賦值）

可以使用多分支結構 `if / elif / else` 依序檢查這三種互斥的情形。

## 範例格式

| 使用者輸入 | 輸出 | 範例說明 |
|-----------|------|---------|
| 10 5 | A > B | 10 大於 5 |
| 3 8 | A < B | 3 小於 8 |
| 7 7 | A == B | 兩數皆為 7，彼此相等 |
| 0 0 | A == B | 兩數皆為 0，彼此相等 |
| -2 3 | A < B | -2 小於 3 |

## 輸入格式規定

- 第一行：兩個整數 A 和 B，以一個半形空格分隔（-10000 ≤ A, B ≤ 10000）

## 輸出格式規定

- 第一行：輸出 `A > B`、`A < B` 或 `A == B`（符號兩側各有一個空格）

## 評測測資規劃 (Test Cases)

1. `10 5` -> `A > B` (正數且前大後小)
2. `3 8` -> `A < B` (正數且前小後大)
3. `7 7` -> `A == B` (正數相等)
4. `0 0` -> `A == B` (零與零相等)
5. `-2 3` -> `A < B` (負數與正數)
6. `5 -5` -> `A > B` (正數與負數)
7. `-10 -20` -> `A > B` (兩負數比較)
8. `10000 10000` -> `A == B` (最大界限相等)

## 核心概念

- 同行多輸入讀取：`a, b = map(int, input().split())`
- 關係運算子：`>`、`<`、`==`
- 多分支條件：`if / elif / else`
