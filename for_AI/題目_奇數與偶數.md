# 奇數與偶數 (Odd or Even)

## 問題描述

請寫一個程式，輸入一個整數 N，判斷它是奇數還是偶數。若是奇數輸出 `Odd`，若是偶數輸出 `Even`。

## 題目說明

在數學上：
- 能被 2 整除的整數稱為**偶數**（除以 2 的餘數為 0）。例如：-4, -2, 0, 2, 4, 6...
- 不能被 2 整除的整數稱為**奇數**（除以 2 的餘數不為 0）。例如：-3, -1, 1, 3, 5...
- 特別注意：**0 是偶數**。

在 Python 中，你可以使用取餘數運算子 `%` 來求除以 2 的餘數：若 `n % 2 == 0`，則為偶數。

## 範例格式

| 使用者輸入 | 輸出 | 範例說明 |
|-----------|------|---------|
| 7 | Odd | 7 除以 2 餘 1，為奇數 |
| 4 | Even | 4 除以 2 餘 0，為偶數 |
| 0 | Even | 0 為偶數 |
| -5 | Odd | -5 為奇數 |
| -8 | Even | -8 為偶數 |

## 輸入格式規定

- 第一行：一個整數 N（-10000 ≤ N ≤ 10000）

## 輸出格式規定

- 第一行：若 N 為奇數輸出 `Odd`，若為偶數輸出 `Even`

## 評測測資規劃 (Test Cases)

1. `7` -> `Odd` (正奇數)
2. `4` -> `Even` (正偶數)
3. `0` -> `Even` (零邊界)
4. `-5` -> `Odd` (負奇數)
5. `-8` -> `Even` (負偶數)
6. `1` -> `Odd` (最小正奇數)
7. `10000` -> `Even` (上限正偶數)
8. `-9999` -> `Odd` (下限負奇數)

## 核心概念

- 變數與整數轉型：`n = int(input())`
- 算術運算子：取餘數 `%`
- 二選一條件分支：`if / else`
- 關係運算子：`== 0`
