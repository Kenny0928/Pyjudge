# 1 加到 N 的總和 (Sum from 1 to N)

## 問題描述

請寫一個程式，輸入一個正整數 N，計算從 1 一直加到 N 的總和（即 1 + 2 + 3 + ... + N）並輸出。

## 題目說明

累加（Accumulation）是電腦解決問題的最核心思考模式之一：
1. **準備一個存錢筒**：在迴圈開始前，建立一個累加器變數 `total`，並將初始值設為 `0`。
2. **依序把東西放進去**：使用迴圈走訪 1 到 N，每一輪把當前的數字加入 `total`（`total = total + number`）。
3. **報出最後金額**：在迴圈完全結束後，用 `print(total)` 輸出總和。

注意：`total = 0` 必須寫在迴圈的**外面**，否則每一輪都會被重新歸零！

## 範例格式

| 使用者輸入 | 輸出 | 範例說明 |
|-----------|------|---------|
| 5 | 15 | 1 + 2 + 3 + 4 + 5 = 15 |
| 1 | 1 | 只有 1，總和為 1 |
| 10 | 55 | 1 加到 10 = 55 |
| 100 | 5050 | 高斯經典問題：1 加到 100 = 5050 |

## 輸入格式規定

- 第一行：一個正整數 N（1 ≤ N ≤ 1000）

## 輸出格式規定

- 第一行：一個整數，代表 1 到 N 的總和

## 評測測資規劃 (Test Cases)

1. `5` -> `15` (一般測試)
2. `1` -> `1` (最小正整數邊界)
3. `2` -> `3` (極小累加)
4. `10` -> `55` (十位數)
5. `50` -> `1275`
6. `100` -> `5050`
7. `500` -> `125250`
8. `1000` -> `500500` (上限邊界)

## 核心概念

- 累加器模式（Accumulator Pattern）：`total = 0` 初始化
- 迴圈迭代：`for number in range(1, n + 1):`
- 變數自加：`total += number`
- 迴圈結束後單次輸出
