# 直角三角形星星塔 (Right-Angled Star Tower)

## 問題描述

請寫一個程式，輸入一個正整數 N，輸出一個由星號 `*` 組成的直角三角形星星塔，共有 N 行：
- 第 1 行輸出 1 個 `*`
- 第 2 行輸出 2 個 `*`
- 第 3 行輸出 3 個 `*`
- ...
- 第 N 行輸出 N 個 `*`

## 題目說明

這題是帶領自學者邁入**巢狀迴圈（Nested Loops）或字串重複運算**的第一步：
- **外層迴圈**：控制「現在是第幾行」（行數 $i$ 從 1 到 N）。
- **內層動作**：在第 $i$ 行印出 $i$ 個星號。在 Python 中，你可以使用字串乘法 `'*' * i`，也可以使用內層迴圈連續輸出。

## 範例格式

| 使用者輸入 | 輸出 | 範例說明 |
|-----------|------|---------|
| 4 | *<br>**<br>***<br>**** | 共 4 行，每行星號數量為 1, 2, 3, 4 |
| 1 | * | 最小三角形，只有 1 個星號 |
| 3 | *<br>**<br>*** | 共 3 行 |

## 輸入格式規定

- 第一行：一個正整數 N（1 ≤ N ≤ 50）

## 輸出格式規定

- 共 N 行：第 i 行輸出 i 個半形星號 `*`（1 ≤ i ≤ N）

## 評測測資規劃 (Test Cases)

1. `4` -> `*\n**\n***\n****` (一般情況)
2. `1` -> `*` (最小邊界)
3. `2` -> `*\n**`
4. `5` -> 5 行星號
5. `8` -> 8 行星號
6. `15` -> 15 行星號
7. `30` -> 30 行星號
8. `50` -> 上限邊界 50 行星號

## 核心概念

- 雙重結構思考：行數與每行字元數的關聯
- 迴圈變數在輸出中的應用：第 $i$ 行印 $i$ 個
- Python 字串乘法 `'*' * i` 或巢狀迴圈
