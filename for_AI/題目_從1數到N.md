# 從 1 數到 N (Count from 1 to N)

## 問題描述

請寫一個程式，輸入一個正整數 N，從 1 開始依序輸出到 N，每個數字各占一行。

## 題目說明

在程式設計中，當我們需要讓電腦執行固定次數的重複動作，並且每一輪都需要用到目前是第幾次時，`for` 迴圈是最好的工具。  
在 Python 中：
- `range(1, N + 1)` 會產生從 `1` 到 `N` 的連續整數數列（終點不包含，因此要寫到 `N + 1`）。
- 迴圈變數在每一輪會自動更新為下一個整數。

## 範例格式

| 使用者輸入 | 輸出 | 範例說明 |
|-----------|------|---------|
| 5 | 1<br>2<br>3<br>4<br>5 | 從 1 數到 5，共 5 行 |
| 1 | 1 | 邊界情況，只數 1 |
| 3 | 1<br>2<br>3 | 數到 3 |

## 輸入格式規定

- 第一行：一個正整數 N（1 ≤ N ≤ 100）

## 輸出格式規定

- 共 N 行：每一行輸出一個整數，從 1 遞增至 N

## 評測測資規劃 (Test Cases)

1. `5` -> `1\n2\n3\n4\n5` (一般情況)
2. `1` -> `1` (最小正整數邊界)
3. `2` -> `1\n2` (小數值)
4. `10` -> `1\n...\n10` (二位數)
5. `20` -> 20 行連續整數
6. `50` -> 50 行連續整數
7. `99` -> 99 行連續整數
8. `100` -> 最大界限 100 行

## 核心概念

- 迴圈結構：`for number in range(1, n + 1):`
- 迴圈變數輸出：`print(number)`
- 區間開閉性理解：`range(start, stop)` 不包含 `stop`
