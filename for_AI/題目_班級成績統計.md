# 班級成績統計 (Class Grade Statistics)

## 問題描述

老師拿到全班 N 位學生的考試成績，需要快速計算出：
1. 全班的**平均成績**（四捨五入輸出到整數）
2. 全班達到**及格門檻（60 分以上，含 60 分）**的總人數

請寫一個程式幫助老師計算並依序輸出這兩個數值。

## 題目說明

這道題目綜合了兩種重要的模式：
1. **累加器（計算總分）**：將所有成績加總 `total = total + score`，全班平均即為 `total // N`（整數除法，或 `round(total / N)`，本題明定取整數商即可）。
2. **條件計數器（計算及格人數）**：每遇到一個 `score >= 60`，及格計數器 `pass_count = pass_count + 1`。

## 範例格式

| 使用者輸入 | 輸出 | 範例說明 |
|-----------|------|---------|
| 5<br>80 50 60 90 70 | 70<br>4 | 總分為 80+50+60+90+70 = 350<br>平均分 = 350 / 5 = 70<br>及格分數（≥60）有 80, 60, 90, 70，共 4 人 |
| 3<br>40 59 30 | 43<br>0 | 總分 129，平均 129 // 3 = 43；無人及格，及格人數為 0 |
| 1<br>60 | 60<br>1 | 剛好 60 分算及格 |

## 輸入格式規定

- 第一行：一個正整數 N（1 ≤ N ≤ 100），代表學生人數
- 第二行：N 個整數，以半形空格分隔（0 ≤ 成績 ≤ 100）

## 輸出格式規定

- 第一行：全班平均成績（整數商 `total // N`）
- 第二行：及格人數（整數）

## 評測測資規劃 (Test Cases)

1. `5\n80 50 60 90 70` -> `70\n4` (一般測資)
2. `3\n40 59 30` -> `43\n0` (全部不及格邊界)
3. `4\n100 100 100 100` -> `100\n4` (全部滿分)
4. `1\n60` -> `60\n1` (剛好 60 邊界測試)
5. `1\n59` -> `59\n0` (59 不及格邊界)
6. `6\n0 0 0 0 0 0` -> `0\n0` (全零狀態)
7. `4\n70 71 72 73` -> `71\n4` (整除平均)
8. `7\n85 92 58 60 77 43 100` -> `73\n5` (多元分布)

## 核心概念

- 同時運用「累加器」與「條件計數器」
- 邊界值判斷：`score >= 60`
- 整數除法 `//`
- 多行輸出規格
