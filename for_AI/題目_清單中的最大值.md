# 清單中的最大值 (Maximum in List)

## 問題描述

請寫一個程式，輸入 N 個整數，找出並輸出其中的最大值。

## 題目說明

在大量數據中找出「最大值」或「最小值」，是資料處理中最基本且最常見的任務。  
經典的解題演算法思維如下：
1. 先假設**第一個數字是目前的衛冕冠軍（最大值）**：`max_val = nums[0]`。
2. 從第二個數字開始，依序跟目前的冠軍比較：
   - 如果發現有數字比目前的 `max_val` 還要大，就讓它成為新的冠軍：`max_val = num`。
3. 走訪完所有數字後，`max_val` 中留下的就是真正的最大值。

**⚠️ 重要防錯提醒**：  
千萬不能把初始值固定設為 `0`！因為如果整串清單全都是負數（例如 `-5, -10, -3`），若初始值設為 0，最後會錯誤地輸出 0。正確做法是將初始值設為清單中的第一個元素 `nums[0]`。

## 範例格式

| 使用者輸入 | 輸出 | 範例說明 |
|-----------|------|---------|
| 5<br>12 35 7 89 24 | 89 | 5 個數字中，最大值為 89 |
| 4<br>-10 -5 -20 -3 | -3 | 全為負數，最大的數字是 -3 |
| 1<br>42 | 42 | 只有一個數字，最大值就是它自己 |
| 3<br>100 100 100 | 100 | 數字皆相同 |

## 輸入格式規定

- 第一行：一個正整數 N（1 ≤ N ≤ 100），代表清單中的數字個數
- 第二行：N 個整數，以半形空格分隔（-10000 ≤ 每個數字 ≤ 10000）

## 輸出格式規定

- 第一行：輸出清單中的最大整數

## 評測測資規劃 (Test Cases)

1. `5\n12 35 7 89 24` -> `89` (一般正整數)
2. `4\n-10 -5 -20 -3` -> `-3` (全負數邊界，防 0 初始化錯誤)
3. `1\n42` -> `42` (N=1 極小邊界)
4. `3\n100 100 100` -> `100` (全部相等)
5. `5\n99 88 77 66 55` -> `99` (最大值在第一個)
6. `5\n11 22 33 44 55` -> `55` (最大值在最後一個)
7. `6\n0 0 0 0 0 0` -> `0` (全零狀態)
8. `8\n-10000 5000 0 -300 10000 7 88 -1` -> `10000` (含正負極限值)

## 核心概念

- 一維清單（List）輸入：`nums = list(map(int, input().split()))`
- 最值尋找演算法：以 `nums[0]` 正確初始化
- 清單走訪與比較更新：`for x in nums: if x > max_val: max_val = x`
